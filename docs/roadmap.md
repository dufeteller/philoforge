# Roadmap

1. Choose license, application stack, storage, and pinned Lean toolchain.
2. Define versioned axioms, definitions, theories, universes, and proof records.
3. Implement axiom library and theory/universe composition with vocabulary checks.
4. Add isolated Lean verification with resource limits and explicit result states.
5. Add accounts, forks, comparisons, discussions, and review.

Acceptance for the first product milestone: a contributor can select versioned axioms, save a universe, submit a proof, and inspect the exact assumptions and verification outcome.
